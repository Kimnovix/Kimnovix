### What I Build

**Project 1: Kimnovix Agri-OS [Edge Systems & Architecture]**
- **Problem:** Agricultural edge environments lack reliable internet, forcing reliance on fragile spreadsheets and human memory for critical clinical and agronomic decisions.
- **Solution:** Engineered an offline-first, deterministic operating system featuring KVB-compliant veterinary dosing (mg/kg), an automated crop agronomy calculator, and a Swine Markov behavioral digital twin.
- **Tools:** Python 3.11, FastAPI, Streamlit, Docker Compose, Deterministic RAG
- **Result:** Replaces guesswork and cloud dependency with mathematically rigid, locally containerized farm intelligence via a command terminal and WhatsApp webhook.
- **Code:** https://github.com/Kimnovix/kimnovix-agri-os

**Project 2: AI Client Operations Suite [AI + APIs]**
- **Problem:** Field supervisors and enterprise teams waste hours manually logging data, evaluating environmental conditions, and summarizing meetings.
- **Solution:** Engineered a suite of Python CLI tools and autonomous agents utilizing the Anthropic SDK and OpenWeatherMap API for stateful chat, structured JSON data extraction, and tool-calling execution.
- **Tools:** Python, Anthropic SDK (Claude Haiku), REST APIs, JSON Schema
- **Result:** Replaces manual field reporting and synthesis with deterministic, AI-driven terminal applications.
- **Code:** https://github.com/Kimnovix/kimnovix-ai-client-operations

**Project 3: SMP Tracker [ML + API]**
- **Problem:** Manually tracking fitness data and calculating coaching parameters took excessive time and lacked predictive insight.
- **Solution:** Engineered an automated predictive pipeline that evaluates daily biometric inputs against a trained machine learning classifier to generate immediate coaching feedback.
- **Tools:** Python, scikit-learn, pandas
- **Result:** Delivers prediction and coaching instantly while exporting a weekly JSON report.
- **Code:** https://github.com/Kimnovix/smp-tracker

**Project 4: API Dashboard [Data Pipeline]**
- **Problem:** Community performance metrics were fragmented, making it difficult to assess protocol adherence and skill engagement at a glance.
- **Solution:** Built a terminal-based analytics dashboard that parses raw community data, computes averages, and generates text-based data visualizations.
- **Tools:** Python, built-in JSON libraries
- **Result:** Consolidates unstructured data into a unified visual summary and structured JSON export in a single command.
- **Code:** https://github.com/Kimnovix/api-dashboard

**Project 5: Browser Coach [Web Tool]**
- **Problem:** End-users needed performance prediction without the friction of installing local Python environments or server backends.
- **Solution:** Developed a client-side prediction engine and coaching generator that manipulates the DOM to run entirely in the browser.
- **Tools:** JavaScript, DOM API, Fetch API
- **Result:** Delivers zero-setup coaching accessible on any device with a web browser.
- **Code:** https://github.com/Kimnovix/browser-coach
